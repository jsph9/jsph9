### Featured Projects

* **[Grafo Temporal PLN](https://github.com/jsph9/PLN-Consulta-de-Perfiles):** Grafo de conocimiento temporal de actores políticos peruanos a partir de 50,000 noticias y 1.9 millones de menciones.
